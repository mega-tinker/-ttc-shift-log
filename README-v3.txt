TTC Shift Log v3

Changes:
- Actual Finish is optional.
- Save a shift before it is finished.
- OT displays Pending until Actual Finish is entered.
- Later use History > Edit to enter Actual Finish.
- OT then calculates automatically from Scheduled Finish to Actual Finish.
- If Actual Finish equals Scheduled Finish, OT is 0:00.
- Paid calculates automatically from Scheduled Start to Scheduled Finish.
