TTC Shift Log v7

This is the full compiled package. No separate fix file is needed.

Rules included:
- Platform = Scheduled Start → Scheduled Finish.
- If you enter multiple shifts on the same date, platform is combined for that day.
- First 8:00 daily platform = regular rate.
- Daily platform over 8:00 = 1.5x.
- Blank Actual Finish means no OT entered; OT shows 0:00, not Pending.
- Only entered Actual Finish creates OT.
- All OT entries on the same date are combined.
- Daily OT under 0:10 = Unpaid OT.
- Daily OT 0:10 or more = full daily OT is Paid OT at 2x.
- Step-back stays separate at 1x.
- Weekly Summary, Daily Breakdown, History filters, photos, 6-month photo cleanup,
  backup/restore, and clickable all-time work summary are included.

Upload/replace the files in the root of the GitHub repository.
