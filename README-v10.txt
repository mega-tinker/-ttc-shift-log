TTC Shift Log v10 — Complete Package

History ordering improvement:
- Newest first:
  * Newer dates appear first.
  * If multiple shifts are on the same date, the later scheduled start appears first.
    Example: 14:23 appears above 05:23.
- Oldest first:
  * Older dates appear first.
  * If multiple shifts are on the same date, the earlier scheduled start appears first.

All v9 features and pay rules remain unchanged.
