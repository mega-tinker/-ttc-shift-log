TTC Shift Log v6 fixed

Key rules:
- Platform is automatically Scheduled Start -> Scheduled Finish.
- Multiple shifts on the same date are combined for daily platform.
- First 8:00 of combined daily platform = regular.
- Daily platform above 8:00 = 1.5x.
- OT is combined across every shift on the same date.
- Daily combined OT under 0:10 = unpaid.
- Daily combined OT 0:10 or more = the full daily OT is paid at 2x.
- If any shift for that date still has Actual Finish pending, that day's paid/unpaid OT remains Pending.
- Step-back stays separate at 1x.
- Weekly summary, daily breakdown, history filters, photos, and all-time drill-downs remain included.
