TTC Shift Log — Offline iPhone PWA

Features:
- New Shift form
- History search
- Edit/delete records
- Summary totals
- CSV export
- JSON backup/restore
- Offline use after initial load

Important:
To install as an iPhone app, these files must be hosted over HTTPS.
Opening index.html directly from the Files app is not enough for full PWA/offline support.

Install on iPhone:
1. Host this folder on an HTTPS static host such as GitHub Pages.
2. Open the hosted address in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Open the TTC Log icon once while online.
6. After that, the app shell and saved records work offline.

Backup:
Records are stored on the iPhone in browser storage. Use Backup JSON regularly and save the backup to iCloud Drive.
